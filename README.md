# Cherry-Leaf-Disease-Classification
CNN-based cherry leaf disease classification using a modified AlexNet architecture, improving F1-score from 0.92 to 0.96 and Macro F1 from 0.89 to 0.94.

A computer vision project for classifying cherry leaf images into multiple disease and healthy-leaf categories using an AlexNet-based Convolutional Neural Network.

### Key Results
- Processed and classified images at **224 × 224 × 3** resolution.
- Split the dataset into **70% training, 15% validation, and 15% testing**.
- Built a baseline **AlexNet-based CNN** achieving approximately **92% accuracy**.
- Improved the model architecture using **Batch Normalization, Global Average Pooling, Dropout, and data augmentation**.
- Improved **F1-score from 0.92 to 0.96**.
- Improved **Macro F1 from 0.89 to 0.94**, indicating better performance across classes.
- Improved F1-score for challenging classes such as **Cherry Normal Leaf and Cherry Shot Hole Disease from 0.81 to 0.88**.
- Improved **Cherry Brown Spot F1-score from 0.91 to 0.95**.

### Technologies
Python, TensorFlow, Keras, CNN, AlexNet, OpenCV, Scikit-learn
